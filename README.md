# Travel Insurance Purchase Prediction

## Project Objective
This project predicts whether a customer is likely to purchase travel insurance using machine learning classification techniques.

## Dataset
The dataset contains 101,000 customer records and 9 variables, including demographic, income, family, health, and travel-related information.

## Models Used
- Logistic Regression
- Random Forest Classifier
- Tuned Random Forest using RandomizedSearchCV

## Best Result
The original Random Forest achieved the highest test accuracy of **83.37%**.

## Tools & Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Jupyter Notebook.
